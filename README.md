# vocoder-proj

Вокодер реального времени на Python для передачи речи по узкополосным радиоканалам.
Параметрический LPC-вокодер в духе LPC-10: вместо звуковой волны передаются параметры
речи (огибающая спектра, основной тон, признак вокализованности, громкость), по которым
приёмник синтезирует речь заново.

> Проект в разработке.

## Характеристики

| Параметр                   | Значение                                              |
|----------------------------|-------------------------------------------------------|
| Битрейт                    | <= 1.1 кбит/с в канале (цель - 1.0 кбит/с)            |
| Текущий режим              | 2400 бит/с (формат кадра LPC-10, 54 бита на кадр)     |
| Частота дискретизации      | 8 кГц                                                 |
| Длительность кадра         | 22.5 мс (180 отсчётов)                                |
| Порядок LPC                | 10                                                    |
| Режим работы               | реальное время                                        |
| Целевая платформа          | ПК, Raspberry Pi                                      |

## Качество

Тестовый набор: 30 фраз на русском языке (15 мужских и 15 женских голосов), 8 кГц.
PESQ - оценка качества (шкала примерно 1-4.5), STOI - оценка разборчивости (0-1).

| Вариант, 2400 бит/с                  | PESQ | STOI  |
|--------------------------------------|------|-------|
| Эталонный LPC-10e (DoD, 1993)        | 2.15 | 0.786 |
| vocoder-proj                         | 2.30 | 0.813 |

## Демонстрация

Оригинал, эталонный LPC-10e и vocoder-proj (оба 2400 бит/с) звучат по очереди; на экране
спектрограммы всех трёх вариантов, звучащий подсвечен.

## Установка и запуск

Требуется Python 3.13 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run vocoder roundtrip input.wav output.wav    # wav -> биты -> wav
uv run vocoder encode input.wav speech.bin       # wav -> файл кодов
uv run vocoder decode speech.bin output.wav      # файл кодов -> wav
uv run pytest -q                                 # тесты
```

## Данные

- `data/testset/` - тестовый набор (см. `data/testset/SOURCE.md`).
- `data/out/lpc10/` - результат работы вокодера на тестовом наборе.
- `data/ab/` - файлы для сравнения на слух: оригинал, эталонный LPC-10e, прошлая и текущая
  версии вокодера подряд (перед каждым вариантом - столько коротких гудков, какой он по счёту).

## Источники

- **FLEURS** (Google) - корпус речи, из русской части которого собран тестовый набор.
  Лицензия CC BY 4.0. https://huggingface.co/datasets/google/fleurs
  A. Conneau et al. "FLEURS: Few-shot Learning Evaluation of Universal Representations
  of Speech", 2022.
- **LPC-10e** - реализация стандарта FS-1015 Министерства обороны США (1993), переведённая
  на C; используется как эталон для сравнения. https://github.com/jafingerhut/lpc10
- **FS-1015 / FIPS 137** - стандарт вокодера LPC-10 на 2400 бит/с.
- **YIN** - A. de Cheveigne, H. Kawahara. "YIN, a fundamental frequency estimator for speech
  and music", JASA, 2002. Используется (с изменениями) для определения основного тона.
